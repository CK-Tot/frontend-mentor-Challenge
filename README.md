# Frontend Mentor Challenges 

This repository contains my solutions to various front-end coding challenges from [Frontend Mentor](https://www.frontendmentor.io). 

I am using these projects to build a robust software engineering portfolio, bridging the gap between my Computer Science coursework and real-world web development. My current focus is on mastering core web technologies and vanilla JavaScript mechanics before fully transitioning into component-based frameworks.

## 🎯 Learning Objectives

Through these challenges, I am actively practicing and refining:
*   **Vanilla JavaScript Mastery:** Deepening my understanding of core JS concepts, closure, and asynchronous operations.
*   **Manual DOM Manipulation:** Interacting with and updating the Document Object Model without abstracting it away.
*   **State Management:** Handling application state cleanly and efficiently in vanilla JS.
*   **Test-Driven Development:** Implementing unit testing and code coverage using Jest.
*   **Responsive Design:** Translating static Figma/Sketch designs into fluid, mobile-first layouts using semantic HTML5 and modern CSS.

## 🧰 Tech Stack

*   **Languages:** HTML5, CSS3, JavaScript (ES6+)
*   **Testing:** Jest
*   **Future Scope:** React (incorporating after cementing vanilla fundamentals)
*   **Environment:** PyCharm / Visual Studio
